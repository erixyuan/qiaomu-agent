# 0.5.3 — Custom models and easier API key setup

- Connect OpenAI-compatible, OpenAI Responses, and Anthropic-compatible endpoints through the host network stack. Desktop requests stream without renderer CORS restrictions and use the system proxy.
- Fetch a provider's model list or add exact model IDs manually. Both coexist; refreshing preserves manual names, enabled selections, and model options. Saving configuration and testing inference are separate actions.
- Paste API keys directly with a dedicated button, reveal/hide drafts, and keep mobile setup scrollable when the keyboard opens. Clipboard access only follows an explicit click.
- Preserve provider settings when a save fails, avoid conflicting model updates, and allow selecting chat transcript text.

Interactive Cloudflare challenges or provider-side blocks still need the provider's help. Mobile/older-host transport may buffer responses. Mobile keyboard layout was simulated; physical iOS verification remains outstanding.
