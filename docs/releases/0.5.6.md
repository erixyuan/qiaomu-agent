# 0.5.6 — Open local artifacts as files

- Clicking a downloaded file or local image link opens the actual file in its system default application, instead of creating a Markdown note.
- Local file links offer Open file and Show in Finder (or the system file manager) in their context menu. Saved generated images also offer Show in Finder.
- Handles absolute paths, file URLs, home-relative paths, and vault attachments, including Chinese names and spaces. Missing files report an error without falling back to note creation.
- Ordinary note links and the image preview remain available. The new file actions and errors support Chinese and English; mobile keeps desktop file access unavailable.
